# Power BI dashboard

This directory contains the project dashboard:

- `Credit_Risk_Analysis.pbix`: Power BI report file.
- `Screenshot *.png`: exported dashboard snapshots.

Open the `.pbix` file in Power BI Desktop to inspect or refresh the report.
The screenshots provide a static preview without requiring Power BI.

The dashboard is separate from the planned FastAPI serving layer in
`src/api/`; this directory currently contains no Streamlit application.
