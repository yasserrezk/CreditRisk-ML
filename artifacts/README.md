# Model artifacts

This directory is reserved for generated model artifacts, including:

- Trained model binaries (`.pkl` or `.joblib`).
- Fitted imputers and preprocessing objects.
- Model metadata, feature lists, and evaluation summaries.

Artifacts should be generated by the modeling pipeline rather than committed
manually. Record the model version and the feature schema used to create each
artifact so it can be loaded safely by the future API layer.

No serialized models are currently present in this directory.
