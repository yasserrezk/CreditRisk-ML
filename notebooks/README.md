# Exploratory notebooks

This directory contains notebooks for interactive analysis and prototyping.

- `EDA.ipynb`: exploratory data analysis, distributions, relationships, and
  visualizations for the credit-risk data.

Run the notebook with Jupyter from the repository root so relative paths to
`data/raw/` and `data/processed/` resolve correctly. Keep exploratory
experiments here; reusable data transformations belong under `src/`.
