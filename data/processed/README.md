# Processed data

This directory stores datasets generated by the preparation pipeline:

- `processed_train.csv`: cleaned, imputed, and feature-engineered training data.
- `processed_test.csv`: cleaned, imputed, and feature-engineered test data.

The pipeline replaces `DebtRatio` with `MonthlyDebt` and adds
`NonRealEstateLoans`. Training data retains the `SeriousDlqin2yrs` target;
the test target column is empty because labels are not provided.

Regenerate these files from the raw inputs after changing cleaning,
imputation, or feature-engineering logic. Do not edit generated files manually.
